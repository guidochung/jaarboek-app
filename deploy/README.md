# Jaarboek

Demo voor administratiekantoren: upload het jaarverslag van vorig jaar en de nieuwe Asperion-balans
(PDF of Excel) en krijg een nieuw concept-jaarverslag in dezelfde opmaak.

Je gebruikt je eigen Claude API-sleutel; die wordt alleen in je sessie gebruikt en niet opgeslagen.
Uploads en uitvoer worden na enkele uren van de server verwijderd.
